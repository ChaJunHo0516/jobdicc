# 프리잡 PreJob

**신입사원을 위한 입사 후 직무 언어 교육** 웹서비스 프로토타입입니다.
`index.html` 파일 하나로 동작합니다. 서버·설치 없이 더블클릭해서 열면 되고, 오프라인에서도 핵심 기능이 동작합니다.

- 사이트: https://ChaJunHo0516.github.io/jobdicc/
- 원본: 팀 프로젝트 [Nickname6532/HackerTone](https://github.com/Nickname6532/HackerTone)의 `prejob.html`(커밋 `f70b538` 기준).
  이 폴더의 `index.html`은 원본에 아래 수정 사항을 반영한 버전입니다. 수정 근거와 테스트 결과는 [`CHANGES.md`](CHANGES.md)를 참고하세요.

## 주요 기능
| 구분 | 기능 |
|---|---|
| 직무 학습 | 직무용어 사전(공통·마케팅·개발·영업·인사·재무·설비보전), AI 업무문장 해석기(사전 용어 + 사전에 없는 현장 은어 추정), 상황별 퀴즈 |
| 게임 훈련소 | 용어 스피드런(60초), 용어 짝맞추기, 현장 안전 훈련(2D 시나리오), 오답 집중 훈련, XP·레벨·뱃지·오늘의 미션·랭킹 |
| 우리 회사 | 회사 승인 후 열리는 사내 학습공간: 교육 자료, AI 요약, 확인 퀴즈, 학습 진도 |
| 기업 콘솔 (staff) | 직원 승인·해제, 초대 코드 발급, 교육 자료 등록·승인, AI 요약·퀴즈 검토, 사내 용어집 관리, 감사 로그, 격리 자동 검증 |
| 플랫폼 관리자 | 지표·문의·콘텐츠·기업 테넌트·사용자 관리 (시연용 비밀번호 `1234`) |

## 발표 모드
- `P` 키 또는 하단 **발표 모드** 버튼으로 켜고, 켜진 동안 `→` / `←` 키로 시연 동선을 이동합니다.
- 발표 모드가 꺼져 있으면 방향키는 무시됩니다.
- 발표 직전 하단 **데모 초기화**로 처음 상태로 되돌립니다.

## 원본 대비 수정 사항
1. 발표 모드가 꺼진 상태에서 방향키를 누르면 로그인 계정이 바뀌고 화면이 이동하던 문제를 고쳤습니다(이제 발표 모드에서만 이동).
2. 상단·모바일 메뉴 링크에 `href`가 없어 키보드(Tab)로 접근할 수 없던 문제를 고쳤습니다.
3. 닫힌 모바일 메뉴의 버튼에 키보드 포커스가 가던 문제를 고쳤고, 햄버거 버튼에 `aria-expanded`를 추가했습니다.
4. 호출되지 않거나, 호출하면 오류가 나던 코드와 미사용 CSS를 정리했습니다(`renderPosts`, `like` 등).
5. 데모 초기화 안내 문구를 실제 동작에 맞게 고쳤습니다.

데이터 구조(localStorage 키 `prejob_demo_v6`)는 원본과 같습니다.

## 데이터·보안 안내
알파테크·베타로지스와 그 인물·자료는 모두 가상의 샘플입니다. 통계는 시연용 더미값이고, 안전 시나리오는 실제 안전교육을 대체하지 않는 데모 초안입니다.
로그인·계정 전환·회사별 접근 제한·관리자 비밀번호는 브라우저(localStorage) 안에서만 동작하는 **시연용**이며, 실제 서버 수준의 보안 기능이 아닙니다.
